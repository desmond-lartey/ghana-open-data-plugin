# Using the portal

The portal is organised around five ways in:

| Menu | What it is for |
|---|---|
| **Data** | The catalogue of every dataset, with search and filters |
| **Statistics** | Ghana's national indicators over time, compared with other countries |
| **Regions** | Profiles of the 16 regions and a finder for the 260 districts |
| **Tools** | The GIS workspace, the Data Lab (SQL) and the Earth Engine connector |
| **Developers** | Downloads and data services for code (Python, R, DuckDB, QGIS) |

The analysis tools open in their own tab, so the page you came from stays where you left it.

# Contributing

Thank you for helping. There are three ways in.

## Share data

Use **[Share data](https://www.ghanaopendata.com/contribute)** on the portal (a free account is needed). Describe the data, attach the files or link to them, and the review team checks the licence, the source and the files. Approved datasets are added to `community/datasets/` here automatically.

Please do not open pull requests that add datasets by hand: submissions go through the portal so they can be reviewed with their files.

## Report a problem or suggest an idea

[Open an issue](https://github.com/desmond-lartey/ghana-open-data-plugin/issues/new/choose) and pick the form that fits: a problem with data, a problem with the portal, or an idea.

## Improve the documentation

The documentation is written in Markdown in [`docs/`](docs/) and built with Material for MkDocs. To preview it:

```bash
pip install -r requirements.txt
mkdocs serve
```

Pull requests that fix or improve the documentation are welcome. The documentation is maintained in the project's main repository and copied here, so a maintainer applies accepted changes there; your pull request is credited.

## Code of conduct

Everyone taking part is expected to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
